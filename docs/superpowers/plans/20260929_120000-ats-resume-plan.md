# ATS-Ready HTML Resume & PDF Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a high-performance, ATS-compliant HTML resume page (`/resume`) featuring Jeric Izon as Senior AI & Full-Stack Engineer, complete with print-optimized CSS and one-click PDF download capabilities.

**Architecture:** A dedicated Nuxt 3 page (`pages/resume.vue`) backed by a structured, typed data model (`types/resume.ts`, `data/resume.ts`). Employs semantic single-column HTML5 elements for 100% ATS readability, scoped `@media print` stylesheets for vector PDF printing, clipboard plain-text extraction, and a headless Chrome export script for pre-generating static downloadable PDFs.

**Tech Stack:** Nuxt 3, Vue 3, TypeScript, Tailwind CSS, Nuxt Icon, Headless Chrome.

**Spec:** `docs/superpowers/specifications/20260929_120000-ats-resume-spec.md`

## Global Constraints

- ATS Structure: Strictly single-column linear hierarchy; standard universal headers (`PROFESSIONAL SUMMARY`, `CORE TECHNICAL SKILLS`, `PROFESSIONAL EXPERIENCE`, `SELECTED PROJECTS`).
- Exact Role Title: `Senior AI & Full-Stack Engineer | Laravel • Node.js • NestJS • Vue/Nuxt • AWS | AI Agents • LLMs • Automation | SaaS`.
- Zero em-dashes (Unicode U+2014) in any copy, headings, or metadata (use standard hyphens `-` or commas).
- Print CSS: Black on white (`#111111` on `#FFFFFF`), 0.5in margins, `break-inside: avoid` on experience/project items.
- Dev server restriction: Do not run long-running dev servers or watch processes.
- Git safety: Do not commit to `main` without feature branching or explicit user confirmation.
